# Self Avoiding Random Walker

Self Avoiding Random Walker animates a 3D, pipe-routing random walker attempting to fill its box.  
Start date: 2021-06-13  

## Demo

![Sample screenshot](Picture1.png)

## Dependencies

- [Processing 4.0 beta 1](https://processing.org/download)
  - PeasyCam library

## Installation

Open any of the `*.pde` files with Processing (IDE).

## Usage

1. Launch the program using Processing (IDE).
1. Click and drag the display to rotate the camera. Scroll to zoom.
